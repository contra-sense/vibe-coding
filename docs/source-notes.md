# 资料使用说明

这份手册采用“事实、推导、呈现”三层记录方式。

## 事实层

事实来自页面资料账本中的固定 commit。仓库规则、设计约束、测试架构和审查协议均以对应文件的原文为准。没有来源支持的经验判断不会伪装成项目既有能力。

Agentic Reviewer 资料位于私有仓库。公开页面保留固定 commit 与文件名，同时明确标注访问边界。没有仓库权限的读者会看到 GitHub 404 页面。

## 推导层

第一性原理章节把分散材料压缩成四个基础事实。工程循环、权限链和测试策略是从这些事实继续推导出的实践结构。它们用于解释材料之间的关系，不替代各项目自己的规范。

## 呈现层

Bento 网格用于同时展示多个互相约束的上下文。交互式循环用于呈现同一工作对象随步骤变化的状态。全屏模式把网页章节重组为演示页，但正文和资料账本仍是内容的单一来源。

## 更新规则

更新结论时，需要同时检查来源文件、固定 commit 链接、正文表述和相关测试。只更新链接而不重新核对结论，会破坏资料账本的意义。
