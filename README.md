# Vibe Coding 工程手册

一份写给真实工程现场的中文手册。它讨论的重点很具体。代理什么时候有资格动手，一条规则应该放在哪一层，改完以后谁来证明结果成立。

[在线阅读](https://contra-sense.github.io/vibe-coding/)

## 这本手册解决什么问题

含糊要求通常把现状、期望、边界和权限揉在一起。代理仍然可以生成代码，只是空白处会被猜测填满。代码看起来顺利，工程判断却没有留下来。

手册用一项明确标注为虚构的登录失败改动贯穿全站。同一项工作依次经过三种检查。

- 第一性原理拆开事实、副作用、后置条件和未知结果
- DDD 判断业务语言、不变量、用例编排、外部适配与页面交互各归谁负责
- 对抗式审查主动寻找目标偷换、领域泄漏、证据错版、权限膨胀和未知重试

三种检查最后收束为七步工程路径。每一步都有输入、产物和退出条件。

## 内容地图

### 贯穿演练

一句“登录失败时体验不好，改一下”，到底缺了哪些事实。演练保留未决的焦点规则，不替产品补答案。

### 第一性原理

四个约束先于任何工具。代理不能使用没有进入现场的事实，副作用会留在外部世界，完成消息无法单独证明终态，证据不足时要保存 Unknown。

### DDD 与落点判断

领域层保存业务含义，应用层编排用例，基础设施层适配外部系统，表现层负责人怎样看见和操作。页面提供常见改动的归属判断表，也列出每种泄漏的信号。

### 对抗式审查

审查者读取同一份事实，独立给出放行、退回或未知。观察、提议、批准、执行、验证与人工评价各自拥有明确权限。

### 完整工程路径

路径由观察事实、写期望契约、判定归属、设计最小变更、授权执行、从目标端复验和留下可重放结果组成。

### A3S Test 界面契约

这一章分开四件产物。

- 浏览器可访问快照与 Test Kit 上下文组成观察面
- PRD、设计稿、正式文档或人工决定提供期望候选
- 确定性 Core 规则生成契约报告
- 人明确提交单项或批量问题以后，修复账本才产生修改权限

Test Kit 在稳定浏览器帧以后读取 DOM、开放 Shadow DOM、可访问语义与布局结果。节点包含视口、文档和视觉视口三套几何。组件边界补充归属与应用事实，节点身份留在 WeakMap 侧表里，不向业务 DOM 写测试属性。

设计稿和 PRD 可以生成期望契约草案。冲突与未决问题会保留到人工审核。浏览器观察随后独立发生，两者由确定性规则对账。

### 十段任务包

页面提供空白模板和完整演练，可一键复制。十段分别写任务结果、当前观察、期望来源、领域归属、允许修改、保持不变、验收契约、验证计划、授权与未知、交付。

### Monorepo 现场

先确认代码所属的工作区，再沿领域语言搜索权威实现。测试按照领域、应用、基础设施和表现层分开运行，跨层路径最后用集成或端到端回归收口。

### 七种失控方式

每一种都保留现场、根因、修正动作和重新放行所需证据。内容包括长提示缺事实、前端接管业务、代理自我验收、设计稿冒充观察树、点选问题扩大权限、未知动作自动重试和清理用户工作树。

## 视觉与交互

站点参考 [nyblnet/bento](https://github.com/nyblnet/bento) 的编辑与演示语法，使用深夜蓝和暖纸交替章节、固定比例舞台、安静的播放控件，以及同一对象在连续状态中变化的表达方式。站点没有复制 Bento 的品牌、产品文案或应用实现。

A3S 蓝负责主要动作，珊瑚色只标记审查和风险。正文默认可见，动效只增强首屏与状态切换。页面还提供深浅主题、移动导航和全屏播放手册。

播放手册支持方向键、空格、Page Up、Page Down、Home、End 与 Escape。焦点留在对话框内，关闭以后返回触发按钮。

## 材料边界

主要结论指向页面末尾的资料账本。链接固定到具体 commit，避免上游变化以后让当前判断失去出处。

Agentic Reviewer 属于私有仓库。页面会标明访问限制，未授权访问 GitHub 时会得到 404。手册没有把私有链接写成公共可用材料。

## 本地开发

需要 Node.js 24 与 npm。

```bash
npm ci
npm run dev
```

开发服务器默认运行在 `http://localhost:5173/vibe-coding/`。

## 验证

```bash
npm run check
```

这条命令检查格式，运行 Vitest 回归，执行 TypeScript 类型检查，再构建生产产物。

当前回归覆盖资料 commit、私有来源标识、内容数量、三种镜片切换、七步路径、界面修复流程、任务包复制与播放手册的焦点恢复。

## 项目结构

```text
src/
├── components/       页面章节、交互舞台与播放手册
├── content/          来源、基础推导、工程实践与演示内容
├── hooks/            主题状态
├── styles/           token、布局、章节组件与播放模式
├── App.test.tsx      主要交互回归
└── content.test.ts   内容与来源契约
public/assets/        原创 WebP 视觉资产
.github/workflows/    GitHub Pages 发布流程
```

## 发布

推送 `main` 后，GitHub Actions 会在干净环境中执行 `npm ci` 与 `npm run check`，随后把 `dist` 发布到 GitHub Pages。
